# Protego

Proyecto académico realizado durante el ciclo de Desarrollo de Aplicaciones Multiplataforma (DAM).

## Descripción

Protego es un prototipo web desarrollado como base para un proyecto de gestión. El objetivo fue diseñar la estructura visual, la navegación y la experiencia de usuario de la aplicación antes de su desarrollo funcional.

## Características

* Diseño de interfaz web.
* Estructuración de contenidos y navegación.
* Maquetación responsive básica.
* Definición de la identidad visual del proyecto.

## Tecnologías utilizadas

* HTML5
* CSS3

## Objetivo

Proyecto realizado para practicar la creación de interfaces web, la organización de contenidos y el diseño de experiencias de usuario en entornos digitales.
